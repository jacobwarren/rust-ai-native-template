How to adapt

Start with the actual task's hard question. Choose a representation that exposes its consequences. Copy an interaction only when it serves that purpose; otherwise create another. Use local bundled styling and make the evidence and response mechanism specific to the new task.

Thariq's original gallery supplies additional approaches. We preserve the distinction between learning and merge authorization.
