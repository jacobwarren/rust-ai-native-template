Sixteen places to intervene, on four ladders

“Here's the problem: every task in this template pays the same eight-page, author-and-reviewer ceremony whatever its size, the agent briefs are plain Markdown agents only find through links, the author and reviewer roles live only in prose, and AGENTS.md carries procedure that belongs in deeper docs. Search the codebase and brainstorm the places we could intervene, from cheapest to most ambitious. I'll tell you which ones resonate.”

The ceremony isn't a habit you can talk agents out of. CI's handoff refuses a changed file without a task record, and a record without five pages. A one-character README edit fails on both:

$ xtask handoff --base origin/main

$ git add harness/tasks/typo.json   # partial record
$ xtask handoff --base origin/main

C4

Risk-based tier: which paths, not how many lines

mediumreceipt

transitions.rs:62 protected() · git diff --name-only --no-renames

Small means no path in the 18 protected entries: goldens, config.json, xtask/, and the root Cargo.toml and Cargo.lock. Those are exact paths, so crates/*/Cargo.toml is not protected. No numstat parsing, no binary rule.

Catches
Protected-path edits to tracked files: policy, golden, lockfile and xtask changes.
Misses
A 2,000-line change under crates/ is small, and so is a crate manifest edit that leaves Cargo.lock alone (edition, features). Untracked files at handoff: the diff lists only tracked changes, so a new xtask/src file is invisible until order() runs at completion (blindspot 02). Blindspots 01 and 03 remain.
Cost
C3's callers; protected() is private today.
Risk
All three earlier tasks here touched xtask/, so in this template few tasks would qualify; it bites in adopted repos.
