A6 · Case folding: the guard's bypass, and the author's

On a case-insensitive volume (core.ignorecase=true here) the hook matches spellings, not files. Today's guard, in a clean clone:

Write xtask/src/main.rs                → note: protected policy file, receipt needed
Write XTASK/src/main.rs                → {}
Write HARNESS/goldens/a.json           → {}   (golden: ask on Claude, block on Codex)
Write <root, lowercased>/xtask/src/main.rs → {}   relative() returns "", "outside"

For the default guard, git still reports xtask/, so the receipt and the size check force standard; only the note and the asks are lost. For author mode the last line is a hole: it allows "outside", so a lowercased root lets the author write product code. The fix asks git once and folds both sides of each comparison:

# after root is known (agent-hook.sh:87); || true stays inside $(...):
# an unset key exits 1 and would trip the ERR trap (:8), as :84-85 warn
fold=$(git -C "$root" config --bool core.ignorecase 2>/dev/null || true)
lower() {   # bash 3.2: no ${p,,}
  if [ "$fold" = true ]; then printf '%s\n' "$1" | LC_ALL=C tr '[:upper:]' '[:lower:]'
  else printf '%s\n' "$1"; fi
}
# relative() (:111-123): match the roots folded, keep the tail's spelling
lp=$(lower "$p")
for r in "$root" "$root_cwd" "$root_short" "/private$root_cwd"; do
  case "$lp" in "$(lower "$r")"/*) p=${p:${#r}+1}; break ;; esac
done
# tier() (:126): compare $(lower "$p") with lowered table entries

Run under macOS /bin/bash 3.2: a lowercased root plus XTASK/src/main.rs yields XTASK/src/main.rs; with the key unset nothing folds, as a case-sensitive checkout needs.

Choice ④How much of the folding to do here

Plan's pick: fold the roots and the tier tables in this task. Same file, same receipt as author mode.

Alternative: fold only the roots, which author mode needs regardless, and record the tier-table bypass as guard-case-folding in harness/gaps.json. The receipt and CI already catch that change; the gap entry is about as large as the fix.
