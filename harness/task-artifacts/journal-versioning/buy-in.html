02The pitch

Today, a board saved by any later build that adds a command, a field or a key is a trap. The shipped build says invalid_store with a parser message, or version, and the next save silently replaces the newer board with whatever the user typed since. This change makes the build read a file's format before anything else. It refuses a newer board by name on load, and save leaves the newer board alone. Boards people already have load exactly as before, and what this build saves is byte-for-byte what the old build saved, so rolling back is safe. No command changes, and the driver protocol stays at version 1. Its value comes one release later, when the first format-2 command ships into a world where the previous release already knows to refuse it.
