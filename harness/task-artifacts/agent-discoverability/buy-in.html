02 The pitch

  
A fresh agent answered twelve questions about the harness correctly, but opened 30 files to do it and was misled three times: task-artifact next --help answered with a generic error, agent-stop was called the hook gate when the stop hook runs complete, and the Task size docs said any non-ceremony skill changes freely when the investigate skill must also match its seed (ticket, Problem). Now every command answers --help with its own entry, wrong arguments come back with the usage of the commands they started, both descriptions say who runs what, and the seed rule sits where task size is explained. The help reply keeps its shape, every error is still one line for the stop hook, and the whole change reverts in one commit with no data or config to unwind.
