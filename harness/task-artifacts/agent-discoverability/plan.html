A1 · Data model: the command table

Today the table is a json! literal inside the [] | ["help"] arm (main.rs:79-102), so neither --help nor the fallback can read it. It moves to help::TABLE, a list of (usage, does) pairs that help, usage errors and tests all read. Its keys become patterns: lowercase literal words, UPPERCASE placeholders, optional tail in [ ], alternatives joined by |, which replaces the five spellings blindspot card 02 counted.
