Decision A

Where should the reviewer's return format live?

The hand-over asks for "numbered findings, and a last line FINDINGS: N", but review-artifact's SKILL.md still says a PASS is one sentence. A reviewer that follows the skill leaves the orchestrator counting findings by hand.

Decision A

Lean: as built. Every review step goes through attach() (Deviation 2), so every reviewer started from next already gets the line, and the skill file is outside this ticket.

you
Decision B

Should verdict use the FINDINGS line to catch a summarised reply?

The plan's weakest part was that nothing notices a summary piped in place of the reply. Deviation 4 makes a cheap check possible: with --notes -, refuse input whose last line is not FINDINGS: N matching --findings. It catches a hand-written digest but not one that copies the last line, and it is new scope.

Decision B

Lean: not now. The first real reply ended with the line, but one reply is too little to justify refusing replies that lack it.
