Nine places to hand over the page prompt, cheapest first

“Here's the problem: cargo xtask task-artifact next tells the orchestrating agent which page step comes next and which subagent to start, but not what to hand that subagent, so for every author, review and rewrite the agent looks up the page's prompt in docs/ARTIFACTS.md, fills its braces ({task}, {area}, {problem}, {reference}), finds the exemplar and gathers the last review's findings by hand. Search the codebase and brainstorm the places we could intervene, from cheapest to most ambitious. I'll tell you which ones resonate.”

The pattern: next already knows the page, the task, which pages exist and every review row. It lacks only the prompt text and the brace values. So the cheap options are formatting what it holds. The expensive ones decide where the brace values live and who assembles the message. B01–B08 refer to the blindspot pass's findings.
