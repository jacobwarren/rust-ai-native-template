What the reference code does

  • The advisory compares parsed rows, not files. next reads HEAD's log with git show (history.rs:40-45), parses it and warns when the working rows don't starts_with the committed ones (router.rs:267-275). It says nothing when HEAD has no log or the committed log fails to parse. The commit step, by contrast, only asks git whether reviews.json is dirty (router.rs:236).
  • No struct in the repo uses skip_serializing_if. A search of xtask/, crates/ and experiments/ finds none, so Row sets the precedent.
  • DOC009 will compare bytes, as DOC007 does (checks.rs:202). DOC008 compares lines, and pair C shows where that difference bites.
