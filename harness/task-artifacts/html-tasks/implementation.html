Implementation notes

Every active task has a durable HTML review page spanning unknowns, implementation notes, buy-in and an interactive quiz.

NOTE 01

Observation / changed assumption

The existing task parser and completion gate had no HTML lifecycle contract. Legacy records and honest partial handoffs need explicit handling. A minimal HTML preflight was saved before code edits; the generated lifecycle record was created once its command existed.

Decision and rationale

Add schema v3 active admission, conventional task artifact locations, append-only notes/brief revisions, and deterministic checked-in HTML. Preserve the earlier preflight.html rather than backdating the new renderer snapshot.

Effect on behavior and next steps

All four views are visible from the start; complete tasks require notes plus a brief/quiz published after the latest note. Old unchanged records remain readable. Quiz scores never authorize completion.

NOTE 02

Observation / changed assumption

Public CLI lifecycle, admission, invalid-input and preservation tests pass. Timestamp-only fixture allocation allowed non-exclusive reuse; the fixture now allocates exclusively and a 16-thread independent marker test passes.

Decision and rationale

Retain a mandatory HTML page for each active task and permit honest pending sections only for partial/blocked handoffs. Fix fixture isolation rather than serialize or weaken tests.

Effect on behavior and next steps

Full workspace tests now pass. The quiz event handler separately passed unanswered, wrong-answer and correct-retry checks with a stub DOM. Browser security policy rejected local-file preview, so visual layout and native browser interaction remain unverified.

NOTE 03

Observation / changed assumption

The user compared the single long page with the separate source artifacts and supplied a screenshot showing quiz headings crossing card borders and excessive empty space.

Decision and rationale

Keep one authoritative JSON record but render four standalone HTML artifacts plus a small index. Move question headings inside cards, keep fieldset legends screen-reader-only, hide empty feedback, and use normal-flow navigation instead of a sticky bar.

Effect on behavior and next steps

Unknowns, implementation notes, buy-in and quiz can each be opened and shared independently. All five files are mandatory and byte-checked. The screenshot documents issues in the prior layout; revised visual qualification is still pending.

  • xtask/src/task_view.rs
  • xtask/src/task_view.html
  • xtask/tests/task_artifacts.rs
NOTE 04

Observation / changed assumption

The user required richer interactive discovery rather than the previous summary page. This task record is being explicitly resumed under v4; its original preflight and earlier notes remain intact.
