1 · What Thariq's pages actually do

  • One prompt, one page. Every page opens with the exact prompt, then “What Claude produced” (index.html:352; 07-reference-port.html:336–342). 07's prompt is 230 bytes in the reader's own voice and assumes a session that already knows the client being ported.
  • The page is the bar, not a template. The index promises “paste the prompt, get something like the page” (index.html:352–353). The targets are stock products: 07's prompt names a crate in vendor/rate-limiter (07:338) and ports it to acme-web (:353). Only the HTML was vendored; no tracked path here contains “rate-limiter” or “acme”.
  • Grounding by location. 07 names what it read (“bucket.rs · backoff.rs · budget.rs · 14 tests”, :354), heads each excerpt with a file and line (:381) and cites crate tests by name (burst_at_t0, :548).
  • Interactions carry the reasoning. 07 links matched regions to their notes on hover (:632–647). 06 asks one question at a time, ordered by blast radius (06:339), and each option is a title and a consequence with no recommendation (06:369–373).
  • A reply goes back before code. 07 says “Nothing gets implemented until you sign off on this page” (:350) and copies either “semantics confirmed” or a correction template (:625–630).
  • They load nothing. None of the 12 files contains “http”. Fonts are system stacks (07:22–24). The PR's screenshot script reports 0 external requests and 0 local files for all 12.

3 · Gotchas: where the port diverges or loses something

Candidates were checked, not assumed. One of them is false.

could not check

G1 · One steered session vs subagents and a reviewer

The vendored files say only “What Claude produced” (07:342); the blog post that describes how they were made is not vendored. The port replaces a person's steering with a brief, a fresh author per page and a fresh reviewer, rewritten at most twice (ARTIFACTS.md:13–15, 38–46). In the trial, six of eight pages passed review first time (PR description).

holds

G2 · His pages have no gate

Thariq gives order as advice: “Before any code is written is the cheapest place to find an unknown” (index.html:372). The PR enforces presence and order (artifacts.rs:100–104, 166–188). But order is skipped in CI (B01) and for partial tasks (B02), and a 36-byte marker counts as a page (B03).

holds

G3 · A person answers his interview

06 lists options and waits. Unattended, the port lets the agent answer with its own recommendation (ARTIFACTS.md:79–80). The questions that would change the architecture are then settled by the agent that will build it.

does not hold

G4 · “His pages load fonts or other resources”

They do not: 0 occurrences of “http” in the 12 files, system font stacks (07:22–24), and 0 requests and 0 local files in the screenshot report. The only outbound references are links to index.html and ../index.html, which README.md:10–11 says do not resolve here. Self-containment is kept, not added. The port adds one marker block that the gate checks (artifacts.rs:24).

partly

G5 · The inline stylesheet's cost

The block is 5,125 bytes: 14% of 07's 36,665, and 41,000 bytes across a task's eight pages. It does not stack, though. The trial pages' total CSS, block included, runs 9,356–15,176 bytes each against 9,682–17,103 for the eight exemplars they pair with; the trial's low end sits 326 bytes below theirs, and all eight hold 98,975 against 100,302. The block takes the place of CSS a page would otherwise write.

holds, and it matters

G6 · The bar fails the port's own checks

At 390 px, 04-toolbar-mock.html overflows horizontally (div.stage, span.ann-chip) in the screenshot report, and 07's hover would be questioned under review-artifact.md:28. Reviewers are told to match the exemplar's depth, not its layout, so neither difference should be treated as acceptable because the exemplar has it.

changed

G7 · Eleven pages to choose from become eight required

The index picks pages by situation: “Ask for a blindspot pass when the territory is unfamiliar” (index.html:372). The port requires all eight on every task (ARTIFACTS.md:64), so a one-line change owes five pages before its code (B04). 02, 03 and 04 are optional.

lost here

G8 · “Before you build anything”

07 waits for sign-off. This PR's own pages, this one included, were written after the code, which the gate allows because the record is partial (B02). A correction you send back now changes the next task, not this diff.

over the bar

G9 · The trial's overage is script, not CSS

The eight trial pages total 334,651 bytes against 247,710 for their exemplars (1.35×). Of the 86,941 extra, script is 67,354, markup and text 20,914, and CSS 1,327 fewer. The trial interview alone holds 35,739 bytes of script to 06's 13,661.
