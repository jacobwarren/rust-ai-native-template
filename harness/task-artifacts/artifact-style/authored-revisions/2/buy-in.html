A consistent visual language, a local historical copy

Each page shares readable typography and familiar controls while keeping its own explanation and interaction design.

Consistent

Colors, font stacks, spacing, buttons, input fields, focus rings and small-screen spacing come from foundation.css.

Task-specific

Tables, diagrams, comparison grids, interviews and simulations remain author choices. Reuse tokens in custom layout CSS.

What happens on upgrade?

The style command changes only the working copy. Registering saves a new CSS snapshot beside the new HTML. Old pages continue loading their own old CSS.

Inclusion checks and hashes establish a reproducible bundle. They do not prove that arbitrary page CSS preserves the intended appearance.

Feedback: identify the page and claim to change in the task conversation. Source: xtask/src/artifact_style.rs and artifact_foundation.css.
