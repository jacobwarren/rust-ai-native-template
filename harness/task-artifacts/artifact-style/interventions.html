Where should styling live?

Compare inline styles, a shared remote stylesheet, and a revision-local CSS asset. Inline CSS duplicates bytes; remote CSS breaks historical isolation. A local asset gives one style source per bundle.

Recommended approach

Install the current foundation into each task and snapshot it during registration. No external font or CDN dependency.
