What the ticket does not show

1 The repo's "add a command" recipe would make stats an edit

The add-product-command skill says to add a Command variant (.claude/skills/add-product-command/SKILL.md:15). Every command lands in history and the journal, revision is the journal's length (lib.rs:99), and save writes the journal for load to replay. A stats command would bump the revision, be undoable and get saved.

So: make it an Action next to Inspect (protocol.rs:20-28). Stats then never reaches the journal, so replay and persistence stay correct with no extra code.

2 No test checks the discovered method list

The doc comment says "descriptor compatibility is tested" (protocol.rs:31), but the test only loops over commands (crates/engine/tests/protocol.rs:18). In a clean copy I added Stats {} and a dispatch arm and left the methods literal (protocol.rs:35) alone. Every test still passed, and discovery doesn't list the new method.

Scratch patch used in 2 and 3, as applied (protocol.rs; counts through inspect only to get a reply, not the plan) 
@@ enum Action
     Inspect {},
+    Stats {},
@@ fn dispatch
+            Action::Stats {} => {
+                let t = self.session.inspect()["tasks"].as_array().cloned().unwrap_or_default();
+                let done = t.iter().filter(|x| x["done"] == true).count();
+                Ok(json!({"total":t.len(),"open":t.len()-done,"done":done}))
+            }
