D1 The discovery guard checks one direction, not two

Code revealed

Keep the public API unchanged. The test pins the list to exactly eight names, and each must be admitted (crates/engine/tests/protocol.rs:164-178). Cost: a variant missing from the list still passes every test (probe B), as before stats (brief unknown 2).
